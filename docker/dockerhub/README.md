# KlockIN by Tomeku

KlockIN records employee attendance and supports administrative corrections, company-scoped review, and monthly Daily Time Record exports. The Flutter app captures GPS and a front-camera selfie and syncs recorded punches to the same server.

__NOTICE__

## Deployment

Use the Compose configuration shipped with KlockIN to run PostgreSQL, Redis, the application, and the HTTPS reverse proxy. Obtain the image tag and deployment configuration from your Tomeku project administrator. For a source installation, see the KlockIN repository's README and `docker-compose.prod.yml`.

For support, contact your installation administrator or the Tomeku project administrator through your established support channel.
