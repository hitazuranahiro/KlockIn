# KlockIN security policy

Report a suspected vulnerability in KlockIN by Tomeku through **Report a vulnerability** on this repository's Security tab when private reporting is enabled. Otherwise, contact the Tomeku project administrator through your established private channel. If you run a self-hosted instance, your KlockIN installation administrator can help you reach the project administrator.

A report should include:

- The affected web or mobile version, commit, or image tag.
- The affected feature, expected authorization, and observed behavior.
- Steps to verify the behavior on a development or test installation.
- Relevant logs and screenshots with employee records, credentials, GPS coordinates, and selfie evidence redacted.

Keep vulnerability details and employee data out of public issues. Coordinate disclosure with the Tomeku project administrator.
